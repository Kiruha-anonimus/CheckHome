AuthModule API

Backend-приложение на ASP.NET Core Web API, реализующее систему аутентификации пользователей с поддержкой:

- JWT авторизации
- Email подтверждения через код
- Авторизации через Telegram Bot
- Swagger документации
- SMTP отправки писем
- локального тестирования через ngrok

📌 Описание проекта

Данный проект представляет собой модуль авторизации, который позволяет
пользователям регистрироваться и входить в систему двумя способами:

1. Через Email
2. Через Telegram

После успешной авторизации пользователь получает JWT токен, который используется для доступа к защищённым API методам.

🏗 Архитектура проекта

Проект построен по типовой слоистой архитектуре:

Основные слои:

📁 Controllers
- Обрабатывают HTTP запросы
- Вызывают бизнес-логику из сервисов

⚙️ Services
Содержат основную бизнес-логику:

- EmailService — отправка кода подтверждения
- TelegramService — работа с Telegram Bot API

🗄 Database
- Хранение пользователей
- Хранение сессий подтверждения
- Токены / refresh tokens

🔐 JWT Авторизация

После успешной авторизации пользователь получает JWT токен.
Этот токен используется для доступа к защищённым endpoint’ам:

📧 Авторизация через Email

Как работает:

1. Пользователь вводит email
2. Система генерирует код подтверждения
3. Код отправляется на почту через SMTP
4. Пользователь вводит код
5. Если код верный → выдаётся JWT токен

SMTP настройка

Используется Gmail SMTP

🤖 Тестирование авторизации через Telegram

Авторизация через Telegram Bot требует публичного HTTPS-адреса,
так как Telegram не может обращаться к локальному серверу напрямую (`localhost` недоступен извне).
Нужно использовать ngrok.

🌍 Решение: ngrok

Для тестирования используется ngrok, который создаёт публичный HTTPS-туннель к локальному серверу.

▶️ Запуск ngrok

В терминале необходимо выполнить команду:

ngrok http https://localhost:7186

После этого можно будет нажать кнопку "Авторизироваться через telegram" и протестировать функцию 

⚠️ Ограничения локального запуска

При разработке проект запускается на локальной машине:
https://localhost:7186
